# Sixele LMS Frontend

React + Vite frontend foundation for Sixele LMS.

## Run

```bash
npm install
npm run dev
```

## Architecture

- Permission-driven navigation and UI
- Dynamic roles from a central permission catalog
- Mock authentication/data for frontend-first development
- API service layer reserved for FastAPI integration
