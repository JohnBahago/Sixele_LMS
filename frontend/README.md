# Sixele LMS Frontend v2.7

Academic Records and Certification readiness milestone.

## Added
- Learner Academic Record workspace
- Course history with enrollment, completion, progress and score
- Certificate status and certificate number visibility
- Academic record CSV export
- Backend-driven academic record data
- Existing completion automation and certificate issuance remain integrated

## Local development
```bash
npm install
npm run dev
```

Configure `VITE_API_URL` in `.env` as needed.
